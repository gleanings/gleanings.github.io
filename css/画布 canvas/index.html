📄️简单

路径，简单来说就是一系列的点以及连接这些点的线。任何 canvas 上下文只会有一个"当前路径"。

📄️曲线

beginPath 方法用于开始绘制路径， closePath 方法用于结束绘制路径 , 在这两个语句中间的 arc 方法用于绘制圆形。

📄️填充

使用 fillStyle 设置填充样式 , ctx.fillStyle = ' 颜色 '; 默认的填充样式是不透明的黑色

📄️操作

canvas 状态是指当前画面的所有样式 、 变形 、 裁切的一个快照，以堆（ stack ）的方式保存。使用 save() 和 restore() 方法可以保存和恢复 canvas 状态。

📄️组合

当两个或两个以上的图形存在重叠区域时，默认情况下一个图形画在前一个图形之上。通过指定图形 globalCompositeOperation 属性的值可以改变图形的绘制顺序或绘制方式，从而实现更多种可能。此外，还可以使用 globalAlpha 属性来指定图形的透明度。
